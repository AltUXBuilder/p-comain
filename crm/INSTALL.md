# Installing Vendor Dependencies

## Why vendor/ is not included

The `vendor/` directory is generated by Composer and contains hundreds of megabytes of
third-party packages. It is never committed to source control or distributed as part of
a project. The `composer.json` files in this package define every dependency precisely —
running `composer install` on the server pulls the exact same packages every time.

The same applies to `node_modules/` — these are generated by `npm install` from `package.json`.

## Full First-Deploy Sequence

```bash
# 1. CRM
cd ~/public_html/crm
composer install --no-dev --optimize-autoloader
npm install && npm run build
cp env.crm.production .env
php artisan key:generate
php artisan migrate --force
php artisan db:seed --class=StaffSeeder
php artisan db:seed --class=WorkflowRuleSeeder
php artisan config:cache && php artisan route:cache && php artisan view:cache
php artisan storage:link

# 2. Website (run migrations here — shared DB, website owns the base schema)
cd ~/public_html/website
composer install --no-dev --optimize-autoloader
npm install && npm run build
cp env.website.production .env
php artisan key:generate
php artisan migrate --force        # Runs ALL shared + website migrations
php artisan db:seed --class=DatabaseSeeder
php artisan config:cache && php artisan route:cache && php artisan view:cache
php artisan storage:link
```

> **Migration order matters.** Run `php artisan migrate` from the **website** first,
> then from the CRM. The website migrations create the base shared tables
> (users, products, consultations, orders, etc.). The CRM migrations
> (numbered 2024_01_01_000031 onwards) add CRM-specific tables that reference
> the shared tables as foreign keys.

## Hostinger-Specific Notes

Hostinger shared hosting uses LiteSpeed and may not have `composer` in `$PATH` by default.
If `composer` is not found, use the full path:

```bash
/usr/local/bin/php /usr/local/bin/composer install --no-dev --optimize-autoloader
```

Or upload a `composer.phar` to each app root and run:

```bash
php composer.phar install --no-dev --optimize-autoloader
```

For `npm`, Hostinger Business plan provides Node.js via SSH. If unavailable,
build assets locally and upload the `public/build/` directory manually.
